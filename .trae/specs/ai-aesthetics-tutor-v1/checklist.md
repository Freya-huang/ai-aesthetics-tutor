# AI美学导师智能体 - 验证清单

## 项目基础架构
- [ ] 后端服务可正常启动，健康检查接口返回200
- [ ] 前端开发服务器可正常启动，首页可访问
- [ ] 环境变量配置正确，API密钥可安全读取
- [ ] 前后端CORS配置正确，可正常通信

## 知识库与RAG检索
- [ ] 所有20份知识库文档成功解析导入，无遗漏无乱码
- [ ] 文档元数据正确（文档ID、分类AIA/THE/VIS、标题、版本）
- [ ] 文档分块合理，向量索引构建成功
- [ ] 使用"构图"、"色彩"、"光影"、"模仿说"、"机械复制"等关键词检索，返回相关知识条目
- [ ] 检索结果包含完整来源信息，可追溯到具体文档

## 作品诊断智能体验证
- [ ] 上传非图片格式文件（如.txt、.pdf）时返回明确错误提示
- [ ] 上传超过大小限制的图片时返回明确错误提示
- [ ] 视觉观察记录仅包含客观可观察的画面描述，无"好看"、"糟糕"等价值判断词汇
- [ ] 诊断报告完整包含10个板块：创作目标、视觉现象、值得保留、重点学习、美学知识、多元理解、修改任务、反思问题、使用边界、知识来源
- [ ] 每个美学知识引用都标注了知识库来源，不虚构来源
- [ ] 推荐的继续追问知识点不超过3个，且均来自本次检索结果
- [ ] 点击知识点可正常追问，系统结合"知识点+当前任务摘要"生成新反馈
- [ ] 作品诊断不识别图片中的人物身份，不对作品做审美高低裁决

## 论文解读智能体验证
- [ ] 上传非PDF格式文件时返回明确错误提示
- [ ] PDF文字提取成功，每个段落标注正确页码
- [ ] PDF中的图片可被成功提取并分析
- [ ] 解读报告完整包含10个板块：文献信息、核心观点、研究问题、关键概念、论证结构、经典问题关联、图片案例、贡献局限、建议阅读、来源边界
- [ ] 每个核心观点和引用都标注对应PDF页码，无无依据的概括
- [ ] 经典美学问题关联有明确证据，不虚构理论关联或冒充作者原话
- [ ] 不把模型自身概括冒充为论文作者的原话
- [ ] 推荐的继续阅读知识点来自知识库，有明确来源
- [ ] 点击知识点可正常追问

## 智能体隔离与安全
- [ ] 作品诊断和论文解读使用独立会话，对话历史完全隔离
- [ ] 论文解读内容不会出现在后续作品诊断的结果中
- [ ] 作品诊断内容不会出现在后续论文解读的结果中
- [ ] 所有展示的来源都是知识库中实际存在的条目，无虚构来源
- [ ] API调用失败时显示友好错误提示，不暴露技术细节

## 前端界面验证
- [ ] 首页清晰展示两个任务入口：作品诊断、论文解读
- [ ] 作品诊断页面支持拖拽/点击上传图片，上传后可预览
- [ ] 作品诊断创作意图表单包含：作品类型、使用场景、表达意图、本轮关注点
- [ ] 论文解读页面支持PDF上传
- [ ] 论文解读阅读目的表单包含：阅读目的、关注问题
- [ ] 结果展示区按模板板块清晰排版，易于阅读
- [ ] 来源卡片醒目展示，可点击或查看详情
- [ ] 可点击知识点标签样式明显，交互反馈清晰
- [ ] 追问结果以追加方式展示，不覆盖原有报告
- [ ] 页面加载和处理过程中有明确的加载状态提示
- [ ] 整体界面风格简洁专业，适合教学场景使用

## 端到端流程验证
- [ ] 作品诊断完整流程可走通：首页选择→上传图片→填写意图→提交→查看报告→点击追问→查看追加反馈
- [ ] 论文解读完整流程可走通：首页选择→上传PDF→填写阅读目的→提交→查看报告→点击追问→查看追加反馈
- [ ] 从作品诊断切换到论文解读再切回，上下文无混淆
- [ ] 处理过程中网络中断或API超时时有合理提示
- [ ] 支持中文输入输出，美学专业术语使用准确
